# AI Travel Planner

## Overview

AI Travel Planner is a Python-based travel recommendation system that generates personalized travel plans based on a user's budget, interests, and trip duration.

The program analyzes available destinations, estimates travel expenses, and suggests the most suitable destination within the user's budget. It also provides food recommendations, activities, day-wise itineraries, and AI-generated travel suggestions.

---

## Features

- Personalized travel destination recommendations
- Budget based trip planning
- Cost estimation for hotel, travel, and activities
- Day wise activities
- Food recommendations for each destination
- Activity suggestions
- AI travel tips based on interests and destination
- User-friendly console interface

## AI Suggestions

The system provides additional recommendations based on:

### Interest-Based Tips

- Adventure → Safety equipment and trekking shoes
- Nature → Camera and outdoor clothing
- Beach → Sunscreen and light clothing
- Spiritual → Temple visits and cultural events

### Budget-Based Tips

- Budget below ₹15,000 → Public transport and budget hotels
- Budget above ₹30,000 → Premium hotels and extra activities

### Destination-Specific Tips

Each destination includes customized travel advice to improve the travel experience.
